# 尾盘 · A 股策略研究工作台

基于 AKShare 的股票筛选、当日尾盘分钟回测和可调参数前端。Python 3.10+，前端无构建依赖。工作台仅生成研究信号，不连接券商。

## 启动

```bash
cd /home/gx/workspace/weipan
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m weipan --port 8766
```

打开 <http://127.0.0.1:8766>。没有安装 AKShare 时，`python3 -m weipan` 仍能运行演示和核心测试。真实数据下载需要安装依赖和可访问行情网站的网络。

直接打开 `static/index.html` 会自动跳转到本地服务地址（需先启动服务），避免文件模式下无法加载图表及数据接口。首页优先恢复回测结果；单次尾盘选股记录仍可在历史中载入，或通过对应记录链接打开。

本次开发环境的依赖安装在 `/tmp/weipan-deps`，可以直接使用 `./run.sh`。长期使用建议安装到项目 `.venv`，避免临时目录被系统清理。

## 策略定义

所有数字参数都可以在前端调整。默认规则：

| 条件 | 默认值与口径 |
| --- | --- |
| 市值 | 总市值 50–200 亿元，含边界；不是流通市值 |
| 涨停 | 最近 50 个交易日存在收盘涨停；可以切换为盘中触及涨停 |
| 横盘 | 最近 7 个交易日 `(最高价 / 最低价 - 1) × 100 ≤ 10%` |
| 放量 | 当日截至选股时点的累计量 / 此前 5 个完整交易日均量 > 1.5；基准不含当日，严格大于，等于不买入 |
| 站上均线 | 选股时价格严格高于 MA5；MA5 = 前 4 个交易日收盘价与当前价格的均值 |
| 排除爆量上影线 | 当日截至选股时累计量 ≥ 此前 5 个完整交易日均量 × 2，且上影线占当日价格振幅 ≥ 40% 时，不买入；两项必须同时成立 |
| 14:30 涨幅 | 固定取当日 14:30 结束的 5 分钟 K 线收盘价，相对前收盘价涨幅严格 > 3%；等于 3% 不买入 |
| 选股时点 | 默认 14:50，可在 14:30–14:55 按 5 分钟刻度调整 |
| 买入 | 信号当日 14:30 后，以选股时点之后同一交易日的下一根 5 分钟 K 线开盘模拟成交；按放量倍数降序、代码升序填充名额 |
| 固定止损 | 成交买入价下跌 2%；可卖出时才执行 |
| 均线止盈 | 前一交易日 MA3 ≥ MA5，当前 MA3 < MA5；执行价扣除买卖费用后仍盈利才卖出 |
| 资金 | 初始 100 万，最多 5 只，按权益 / 最大持仓数分配每只预算，现金不足时缩减数量 |
| 股数 | 100 股倍数，科创板首次买入至少 200 股 |
| 费用 | 双边佣金 0.025%，最低 5 元；卖出印花税 0.05%；双边过户费 0.001%；单边滑点 0.05% |

横盘 / 均线窗口包含当前信号日；放量基准取此前完整交易日，不包含当日；盘中使用截至选股时点的价格和累计成交量，不外推全天量。盘中尚未收盘的 K 线不能算“收盘涨停”记录，触及涨停口径可以使用当日已发生的最高价。

新增三项在“买入当日确认”中整体开关，均线天数、爆量基准天数、爆量倍数、上影占比和涨幅阈值均可调整。上影线长度 = `最高价 - max(开盘价, 选股时价格)`；上影占比 = `上影线长度 / (最高价 - 最低价) × 100`，价格振幅为零时占比为零。入场量比和爆量上影线的量比可以分别设置基准天数，两个过滤条件都须满足。

**所有新回测只使用当日尾盘模式**，即使关闭 MA / 上影线 / 涨幅过滤，也不会改用次日开盘买入。14:30 行情缺失时不能用日线收盘涨幅替代。14:50 选股仍使用固定的 14:30 涨幅；均线、成交量和上影线则统计到 14:50，不借用收盘后的完整日 K 判断买入。前收盘参考优先使用供应商提供的当日参考价，缺失时使用上一交易日收盘价。

候选列表显示入场 MA、14:30 涨幅、当日量倍数和上影占比，并新增三项条件核验。新交易保存买入时信号快照，可在日 K 复盘窗口下方核对；完整日 K 可能与当时的部分日线不同。历史记录保留原参数与结果；旧日线记录明确标记“旧版次日成交”，旧分钟记录标记“旧版均量规则”，仅供查看。载入旧结果时，左侧参数会迁移为同日尾盘与当日放量 1.5 倍的新口径，右侧旧收益必须重新回测才会变化。

“7 日横盘”表示至少存在最近这 7 日的区间满足约束，不要求该区间之前也横盘。

## 当日尾盘执行

新回测与选股的 `strategy_version=2`，仅允许 `mode=minute`、`volume_recent=1`。API 和引擎均拒绝日线次日成交及旧版均量参数；旧记录通过专门的历史读取流程查看，不会重新执行旧买入逻辑。

回测要求每个有交易的股票日均有完整的 48 根 5 分钟 K 线。用选股时点已完成的分钟线构造当日部分日线，**当日**下一根 K 线开盘模拟成交。例如 14:30 选股，成交位于当天 14:30–14:35 时段；14:50 选股，成交位于当天 14:50–14:55 时段。买单不会保留到次日。交易明细、CSV 和日 K 复盘均展示信号时间与成交时段；分钟 K 线不能证明精确到秒的成交时间。

卖出继续遵守 T+1：买入当天不能卖出；后续交易日逐根分钟线检查止损，尾盘检查盈利均线下穿。选股时点之后才获得的止损回款不能用于更早的买单。分钟数据不足就停止，不用日线或下一交易日行情替代。

默认日期为最近一周、截至最近已收盘工作日；交易所节假日和具体股票的分钟覆盖仍以真实数据为准。前端提供“使用最近一周区间”，不会自动改动用户已填写的回测日期。

尾盘选股按钮只需要指定日期截至选股时点的数据，可在盘中时点已到后使用，也可复查分钟数据覆盖范围内的历史日期。默认股票池已扩大为 **300 只**，来自 2026-10-19 实际查询到的 2,089 只市值 50–200 亿元的沪深股票；通过固定的代码散列排序抽样，覆盖沪深主板、创业板和科创板，未参考回测收益。以前的 30 只结果作为历史记录保留。

在左侧“回测股票池”可选择 **300 / 500 / 1000 / 全部匹配股票**，再点击“更新 / 扩大股票池”。“全部”返回全部符合范围的股票，不再截断为 300 只；支持最多 8,000 个沪深代码。股票范围可以选当前市值范围，或全部沪深 A 股后在历史回测中逐日筛市值。界面明确显示实际导入数量和每次回测使用数量。

初次下载大股票池较慢，4 个下载进程并行加载；临时接口故障重试一次，已下载历史数据自动复用。刷新页面后可以继续查看当前任务进度。当前股票池有存活偏差；按今天的市值导入后回测过去还存在选择偏差。

## 交易记录查看日 K

电脑端点击 **交易明细 → 对应交易的“日 K ↗”**：

- 显示未复权日 K、成交量、策略短 / 长均线及 MA20。
- B / S 标记使用本笔回测的实际买卖日期和成交价，阴影表示持仓区间，虚线表示该笔固定止损价。
- 显示买卖价格、净盈亏和卖出原因；支持上一笔 / 下一笔切换，包括跨股票交易。
- 支持 60 日 / 120 日 / 全部、滚轮与按钮缩放、滑块平移、“定位交易”，鼠标悬停查看 OHLC 和成交量。
- 新回测会保存发生交易股票的原始日线快照，之后查看不重新下载。旧真实记录优先从原行情缓存恢复；缺少缓存而重新下载时会明确标注。旧演示记录没有快照时要求重新运行，避免用新生成器伪造原始日 K。

## 数据与限制

- AKShare（已验证版本 1.18.88）：`stock_zh_a_hist` 获取未复权日线，`stock_value_em` 获取逐日总市值，`stock_zh_a_hist_min_em(period="5")` 获取分钟数据，`stock_individual_info_em` 核实当前证券简称，`stock_zh_a_spot_em` 生成当前股票池。东方财富行情断连时，日线 / 分钟分别回退到 AKShare 的 `stock_zh_a_daily` / `stock_zh_a_minute` 新浪接口；简称回退到交易所股票列表。回退来源记入每次运行说明。
- 统一使用“手”为成交量单位，新浪返回的“股”除以 100；完整交易日的分钟汇总量必须与日线量相差不超过 5%，否则拒绝生成结果，防止不同数据源单位不一致。
- 日线使用同日期历史市值；分钟信号用 **前一交易日总市值 / 前一日收盘价 × 当前价格** 估算市值，不读取当日收盘市值。股本变更日的盘中市值估算需要单独核验。
- 分钟免费接口通常仅覆盖近期，实际覆盖以返回数据为准。盘中数据缓存 60 秒，当日收盘后缓存 24 小时，已完成的历史区间缓存 30 天；15:10 后刷新盘中缓存。证券池缓存 1 小时。临时接口错误重试一次；任何一只请求股票最终下载失败，整次运行失败，避免静默缩小股票池后输出收益。
- 仅支持沪深 A 股，排除当前名称带 ST、退市标记的证券，至少需要 60 个交易日历史。默认主板涨跌幅限制 10%，创业板自 2020-08-24 起和科创板 20%，价位按分四舍五入。
- **固定股票池有存活偏差**；从今天的市值范围导入股票再回测过去，还会额外产生选择偏差。没有历史全市场证券状态库，不能声称无偏全 A 股回测。
- **未复权价格，不计分红送转和拆并股现金流**；除权可能造成收益和止损失真。虽然日线涨停判断尽量读取交易所前收盘参考价，但持仓与技术指标仍需对除权区间核验。
- 缺少历史 ST、上市初期无涨跌幅限制、特殊限价和完整停复牌状态，无法完全还原交易规则。涨停价不买、跌停价不卖是保守成交假设；不模拟排队、交易冲击与部分成交。
- T+1：买入当日触发止损也不能卖出；次一交易日根据当时行情重新判断触发。止损不是收益下限，跳空、跌停都可能导致更大亏损。
- 期末不强制平仓；净值包含按最近收盘价估值的未平仓头寸。胜率只统计已平仓交易。基准为本次固定股票池的等权价格收益，不是指数，不含费用 / 分红。
- 演示数据是标注明确的合成数据，只用来验证交互和执行流程；模拟日历仅排除周末，不适用于评价策略是否赚钱。

## 工程结构与测试

```text
weipan/config.py     参数及校验
weipan/strategy.py   选股指标和均线下穿
weipan/backtest.py   当日尾盘分钟回放、资金、交易费用
weipan/data.py       演示行情、并行加载、缓存、尾盘选股
weipan/fetch.py      进程隔离的 AKShare 下载器，带请求及总时限
weipan/app.py        本地 HTTP API、任务状态、运行历史、CSV 导出
weipan/universe.py   大股票池导入与固定代码抽样
weipan/charts.py     回测日线快照、旧记录恢复和日 K API
static/             中文响应式前端，无需 Node 构建
data/cache/         AKShare 本地缓存（忽略 Git）
data/runs/          参数、指标、曲线、交易与数据来源记录（忽略 Git）
data/charts/        发生交易股票的原始日 K 快照（忽略 Git）
data/universe-preset.json  当前默认股票池与查询时间
```

浏览器测试支持 `WEIPAN_URL`、`CHROMIUM_PATH` 环境变量。API：`POST /api/backtest`、`POST /api/screen`、`POST /api/universe`；传入参数 JSON 返回任务 ID，通过 `GET /api/jobs/{id}` 取进度和结果。`GET /api/active-job` 恢复正在运行的任务。`GET /api/runs`、`GET /api/runs/{id}` 读取历史；`GET /api/runs/{id}/trades.csv` 导出交易；`GET /api/runs/{id}/candles/{symbol}` 读取日 K 与买卖点。

服务默认只监听 `127.0.0.1`，不提供公共互联网账户 / 登录系统。
